# Prior-guided-U-net
A Dual-Level Prior-Guided U-Net for Reliable Building Extraction from High-Resolution Remote Sensing Images
______________________________________________________________________________________________________________

SGU-Net Overview

SGU-Net (SVM-Guided U-Net) is a hybrid deep learning framework that integrates classical statistical priors into a U-Net architecture to improve robustness and generalization under limited-label and domain-shift conditions. It introduces an external prior–guided attention mechanism and a knowledge-guided loss function to incorporate probabilistic maps generated by an SVM into deep feature learning. The proposed model is evaluated on building extraction from high-resolution remote sensing imagery and demonstrates strong performance with reduced annotation requirements.

Quick Test

For fast evaluation without retraining, a Quick Test folder is provided.
This folder contains both Python scripts and Jupyter Notebook files for inference.

To perform a quick test:
1. Download the trained model weights from the Releases section.
2. Load the weights using the provided test code.

3.Run inference on any input image.

A sample test image is included in the folder for demonstration purposes
